# 🦖 Dino Game with Hand Gesture Control using OpenCV
Control the Google Chrome Dino Game using just your hand gestures!
This fun computer vision project uses your webcam to detect whether your hand is open or closed and controls the Dino accordingly — completely hands-free! 🎮✨

✊ Closed Hand → Dino Jumps

🖐️ Open Hand → Dino Runs

Powered by OpenCV and MediaPipe for real-time hand tracking. 👁️‍🗨️🤖

🚀 Features
✅ Real-time hand tracking using your webcam
✅ Intuitive gesture control (close to jump, open to run)
✅ Replicates the iconic Chrome Dino Game experience
✅ No keyboard required — just wave your hand! 🙌

🧠 Technologies Used
🔹 Python 🐍
🔹 OpenCV – For image processing and video capture
🔹 MediaPipe – For accurate hand landmark detection
🔹 Google Chrome Dino Game – The classic offline runner!

⚠️ Notes
⚡ Make sure your environment has good lighting for optimal hand detection
⚡ You may need to tweak detection thresholds depending on your camera and setup
⚡ Works best in fullscreen mode when playing the Dino game
⚡ Ensure your webcam is not obstructed and is positioned properly
